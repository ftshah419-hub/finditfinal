# FINDIT — Frontend Application (Client)

This directory is designated for the **React + Vite + Tailwind CSS** frontend of the FINDIT platform.

## Team Responsibilities (from `docs/FILE-OWNERSHIP.md`)

- **Person 1**: Authentication UI (Login, Registration, Auth Context, Token Storage).
- **Person 2**: Home, Public Item Browsing, Item Reporting, Claim Submissions, Notifications, and User Profile pages.
- **Person 3**: Admin Dashboard, Item Moderation, Claim Verification, Reports Review, Category Management, AI Matches, and System Settings.

## API Integration

The frontend communicates with the backend API running at `http://localhost:5000/api/v1`.
CORS is configured to accept requests from `http://localhost:5173`.
